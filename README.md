# Caregiver Companion 安装与使用说明

## 安装说明

1. 将 `caregiver-companion` 文件夹放入 OpenClaw skills 目录
2. 启动 OpenClaw 后自动加载

## 使用方法

直接用自然语言描述当前感受或困境，无需上传文件。

示例触发语：
- "今天照顾老人很累..."
- "我觉得压力很大..."
- "心里很难受，想说说..."

## 示例输入

用户："我妈得了失智症，我已经照顾她三年了。有时候真的很崩溃。"

## 示例输出

AI共情回应 + 开放式提问 + 支持性对话（详见SKILL.md示例）

## 已知限制

- 不提供医疗、心理诊断或用药建议
- 不替代专业心理咨询
- 严重情况引导寻求专业帮助
